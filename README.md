# JavaScript Mini Projects 🚀

A collection of beginner-friendly web development projects built using **HTML, CSS, and JavaScript**. These projects were created to practice JavaScript fundamentals, DOM manipulation, events, functions, conditions, form validation, and basic UI design.

---

## 📂 Projects

### 🕐 1. Live Clock

A simple digital clock that displays the current time and updates automatically every second.

#### Features

- Displays the current time
- Updates every second
- Uses the JavaScript `Date` object
- Uses `setInterval()`
- Simple and clean user interface

#### Technologies Used

- HTML
- CSS
- JavaScript

---

### 🎯 2. Number Guessing Game

A simple game where the user tries to guess a randomly generated number.

#### Features

- Generates a random number
- Accepts user input
- Checks the user's guess
- Displays whether the guess is correct or incorrect
- Provides feedback to the user
- Uses JavaScript conditions and functions

#### Technologies Used

- HTML
- CSS
- JavaScript

---

### 📝 3. Registration Form

A registration form with client-side form validation using JavaScript and Regular Expressions.

#### Features

- Name validation
- Contact number validation
- Email validation
- USN validation
- Gender validation
- Course selection validation
- Displays validation messages
- Prevents form submission when invalid data is entered

#### USN Format

The USN follows this format:

**4EK26IS002**

Pattern:

**1 Number + 2 Letters + 2 Numbers + 2 Letters + 3 Numbers**

#### Technologies Used

- HTML5
- CSS3
- JavaScript
- Regular Expressions

---

### 🧮 4. Simple Calculator

A basic calculator built using **HTML, CSS, and JavaScript** that performs common arithmetic operations.

#### Features

- Addition
- Subtraction
- Multiplication
- Division
- Clear/reset functionality
- Button-based number input
- Displays calculation results
- Interactive user interface

#### Technologies Used

- HTML5
- CSS3
- JavaScript

#### Concepts Practiced

- JavaScript functions
- DOM manipulation
- Event handling
- Button click events
- Variables
- Arithmetic operators
- Conditional statements
- Input and output handling
